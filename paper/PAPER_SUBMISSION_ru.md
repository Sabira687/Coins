# ELCVIA: требования и что нужно для сдачи

Источник: страница журнала https://elcvia.cvc.uab.cat/about/submissions (прочитана 9 ноября 2026) и описание шаблона на Overleaf. Модерация и рецензирование нас до дедлайна не касаются: нужно только **отправить** статью.

## 1. Требования журнала (то, что написано на сайте)

| Пункт | Требование |
|---|---|
| Тип | ARTICLE: обычная статья, **8–12 страниц (рекомендуемый объём)** |
| Формат файла | **PDF** (обязательно) |
| Текст | одинарный интервал, **шрифт 11 pt**, курсив вместо подчёркивания (кроме URL) |
| Рисунки и таблицы | **внутри текста** в нужных местах, не в конце |
| Стиль и библиография | по Author Guidelines; подробностей на странице нет, поэтому берём шаблон LaTeX 2e и нумерованные ссылки |
| Шаблон | LaTeX 2e (ссылка на странице журнала; также Overleaf: «ELCVIA Template») |
| Дополнительные файлы | желательны (видео, изображения, .exe) в GIF/JPEG/AVI/MPEG или в .zip |
| Авторские права | остаются у авторов; публикация под CC BY-NC-ND 4.0 |
| Предпринтинг | разрешено и поощряется выкладывать работу заранее (репозиторий, arXiv и т.п.) |
| Плата | у журнала нет платы за подачу и публикацию (по данным поиска, на сайте не перепроверено) |
| Связь | elcvia@cvc.uab.es, тема письма «Article Formats» |

Из старого описания шаблона (могут быть устаревшими, сверить с выданным .cls/.sty): A4, поля сверху и слева 2 см, область текста 17 × 25 см; заголовок Times 16 pt жирный, разделы 14 pt, подразделы 12 pt, аннотация 10 pt, основной текст и подписи 11 pt. Рецензирование **не слепое**: имена авторов видны редактору.

**Чего на странице нет:** ограничений на длину аннотации, количество ключевых слов, стиль цитирования, требований к ИИ-декларации. Декларацию об использовании ИИ мы всё равно добавим (см. CLAUDE.md), это безопасно.

## 2. Что вводится в форму подачи

1. **Регистрация главного автора** на сайте журнала (Login or Register).
2. **Информация о статье:**
   - название;
   - аннотация (вставляется текстом);
   - остальные авторы и их e-mail;
   - предопределённые ключевые слова: **минимум одно общее и одно специфическое** (выбираются из списка на сайте, можно добавить свои);
   - тип выпуска: Regular.
3. **Файл статьи в PDF.**
4. По желанию: дополнительные файлы (например, ссылка или zip с примерами изображений). Датасет лучше дать ссылкой на Google Drive/GitHub внутри статьи.

После отправки нужно сохранить подтверждающее письмо с **номером рукописи** и переслать его преподавателю (по условию курса).

## 3. Что нужно подготовить (чек-лист)

- [ ] Текст статьи на английском, 8–12 страниц, шаблон ELCVIA
- [ ] Рисунки внутри текста (из `results_paper/figures/`, плюс схема пайплайна, которую ещё нужно нарисовать)
- [ ] BibTeX/список литературы: 7 проверенных ссылок из `related_work.md` + ссылки для методов (ResNet, ViT/DINOv2, AdamW, label smoothing, ImageNet; в отчёте A2 они уже проверены)
- [ ] Данные от соавтора: таблица монет P2 (год, состояние), модели телефонов, источник света в P2
- [ ] Данные об авторах: ФИО, аффилиация, e-mail, ORCID (если есть) для обоих
- [ ] Согласие соавтора на подачу и использование его видео
- [ ] Датасет на Google Drive, ссылка в разделе Data Availability и в `DATASET.md`
- [ ] Декларация об использовании ИИ (если применимо)
- [ ] Ключевые слова (общее + специфическое), например: *image classification* / *coin recognition*, *transfer learning*, *specimen generalisation*
- [ ] Проверка PDF: 11 pt, одинарный интервал, рисунки в тексте, объём 8–12 страниц

## 4. Оценка времени (только сдача)

| Этап | Время |
|---|---|
| Регистрация на сайте, чтение шаблона | 0,5 ч |
| Настройка шаблона в Overleaf, подключение рисунков и BibTeX | 1–1,5 ч |
| Написание и перевод текста (вы редактируете сами; основа: план в `PAPER_PLAN_ru.md`) | 8–12 ч, это главная часть |
| Аннотация и введение (последними) | 1–1,5 ч |
| Загрузка датасета на Диск, ссылка | 0,5 ч |
| Сбор недостающих данных у соавтора | зависит от соавтора, запросить сегодня |
| Вычитка, проверка PDF по чек-листу | 1–1,5 ч |
| Форма подачи на сайте | 0,3 ч |
| **Итого** | **около 13–18 ч работы, из них 8–12 ч сам текст** |

Реалистичный порядок на 9–10 ноября: сегодня данные от соавтора, шаблон, разделы Dataset / Models / Protocol / Results (опираются на готовые числа); завтра до вечера Discussion, Limitations, Introduction, Abstract, вычитка, PDF, подача. Если таблица монет P2 не придёт вовремя, сдаём с таблицей без года/состояния и убираем объяснение «трудных» монет из раздела Error Analysis (пункт 6 результатов).

**Риск:** точное время дедлайна 10 ноября неизвестно; лучше уточнить у преподавателя, и подавать с запасом, а не в 23:59.
